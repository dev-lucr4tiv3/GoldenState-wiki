# Trucker

Waren zwischen Lagerhäusern, Häfen und Lieferpunkten transportieren. Einer der lukrativsten Einsteigerjobs.

## Voraussetzungen

Führerschein Klasse C. Beim DVLA-Büro erhältlich — zusätzlich zum normalen Führerschein ist eine praktische Prüfung mit einem Trainer nötig.

## Start

1. Spedition (LKW-Symbol, Industriegebiet La Mesa)
2. Am Terminal anmelden
3. Route aus dem Auftragsbuch wählen
4. LKW aus dem Depot

## Routen

| Route | Schwierigkeit | Verdienst |
|---|---|---|
| Stadtlieferung | Leicht | $600 |
| Hafenroute | Mittel | $1.100 |
| Bergstrecke | Schwer | $1.800 |
| Nachtlieferung | Schwer | $2.400 |

## Wichtig

Ladung vor Abfahrt mit `E` sichern. Maximaltempo auf Autobahnen: 110 km/h. Verlust der Ladung durch scharfe Kurven zieht Abzüge.

:::warning
Wertvolle Lieferungen können überfallen werden.
:::
