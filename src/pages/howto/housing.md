# Wohnung mieten

Optional, aber praktisch. Eine Wohnung gibt dir sicheren Lagerplatz und einen festen Respawn-Punkt.

## Mieten

1. Haus-Symbol auf der Karte
2. `E` an der Tür oder dem Schild
3. "Mieten" wählen, Monatspreis bestätigen
4. Schlüssel ins Inventar

## Preise

| Typ | Monatlich |
|---|---|
| Motelzimmer | $800 |
| Apartment klein | $2.500 |
| Apartment mittel | $5.000 |
| Haus | ab $12.000 |

## Mitbewohner

Von innen `E` an der Tür, "Schlüssel verwalten", Namen eintragen.

## Kündigen

Wohnungsmenü von innen, "Miete kündigen". Gilt zum Monatsende. Vorher alle Gegenstände raus.

:::warning
Fehlender Kontostand zum Monatsersten = Wohnung verloren, Gegenstände weg.
:::
